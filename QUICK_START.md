# Быстрый старт после миграции на Polars

## Важно для Windows Server / старых процессоров

Если ваш процессор не поддерживает AVX2/SSE4, используйте совместимую версию:

```bash
# Удалить стандартную версию
uv pip uninstall polars

# Установить совместимую версию
uv pip install "polars[rtcompat]>=0.20.0"

# Или через sync (если уже обновлен pyproject.toml)
uv sync
```

## 1. Обновить зависимости

```bash
# Синхронизировать зависимости (рекомендуется)
uv sync

# Или установить вручную
uv pip install polars>=0.20.0
```

## 2. Проверить установку

```bash
python -c "import polars as pl; print(f'Polars {pl.__version__} установлен успешно!')"
```

## 3. Запустить приложение

```bash
# Обычный запуск
python -m app

# Или через uvicorn напрямую
uvicorn app.server:app --reload
```

## 4. Проверить логи

Приложение должно запускаться без зависаний. В логах вы увидите:
- Быстрый старт (без задержек на импорт)
- Сообщения о загрузке файлов
- Статистику обработки данных

## Возможные проблемы

### Ошибка: "No module named 'polars'"
```bash
uv pip install polars>=0.20.0
```

### Ошибка: "must specify either a fill `value` or `strategy`"
Это ошибка Polars - метод `fill_null()` требует явного значения.
```python
# Неправильно:
df.fill_null()

# Правильно:
df.fill_null(0)        # для чисел
df.fill_null("")       # для строк
df.fill_null(None)     # для null
# Или просто не вызывать fill_null(), если null значения допустимы
```

### Ошибка при чтении CSV
Проверьте кодировку файла (должна быть utf-8-sig)

### Ошибка типов данных
Polars строже в типизации. Проверьте логи для деталей.
